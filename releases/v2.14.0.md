

### Fixes
- The backend's OpenAPI library is updated to a version without the known crash advisories in the spec loader.
- An official repository's pull request runs no longer show as rejections on the organization page.
- Onboarding and fixes no longer fail with "You do not have sufficient permission to run a pipeline on <branch>" when the default branch only lets specific people run pipelines; the configuration is now validated on the merge request branch itself.
- Onboarding a project whose stages come from an included file no longer fails with "chosen stage test does not exist": the Plumber job joins test when the pipeline has it, otherwise the pipeline's first stage.
- A score push from an official organization's repository no longer waits for the organization page to be rebuilt and signed, so it completes within the CLI's time limit.

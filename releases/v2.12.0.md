

### New
- A registered organization gets a public page, badge and social card with its verified Plumber scores, and a signed attestation anyone can check with cosign.
- The organization page's introduction links the signed push documentation.
- An official organization can be registered without the locked-workflow requirement; its page and attestation say so.
- The organization page no longer shows a banner when the workflow lock is waived.
- The organization page's configuration hash no longer overflows its column.
- Plumber is now available as a hosted GitHub App: install it on a repository and it opens a pull request adding the Plumber workflow, scores every push, and on request repairs the findings it can fix and tells you about the ones it cannot.
- On an organization page, a repository name opens its GitHub repository in a new tab; its Plumber Score report is linked from the expanded row.

### Fixes
- Removing an official organization clears the verified mark on its repositories, an organization page says when it covers only the first 2000 public repositories, and a locked workflow pinned to an older Plumber release above the organization's floor is no longer refused.
- A repository whose .plumber.yaml does not extend the Plumber default is verified against the controls its file enables.
- A repository whose .plumber.yaml leaves default controls out is shown as a custom policy.
- A control enabled under a configuration key the pinned Plumber release does not know no longer blocks verification; the key is listed as ignored.
- A rejected official push tells the CLI which controls were missing or which key did not match, not only the reason code.
- A user's project list now shows every synced project GitLab lets them read, with no 100-group or 100-membership cap; public and internal projects they can read are visible too.
- A Deploy Plumber onboarding is retried when GitLab's CI lint call fails on the way (a timeout, a 5xx, a 429, a cut answer) instead of failing for good; a refused call or an oversize merged configuration fails with a clear message.



### New
- Plumber repairs now refuse to add network calls, secrets or unvetted actions, and harden third-party actions with a workflow lockfile.
- Admins see a header notice when an instance's organization token expires within two weeks, with a link to the connection settings.

### Fixes
- A policy can be saved with portfolios only in its scope, no direct project pick required.
- Nightly snapshot refreshes now run on a dedicated paced queue (PLUMBER_SNAPSHOT_WORKERS, default 4) with a 120 s collection budget, so a large instance no longer floods its GitLab rate limit and loses snapshot data.
- A CLI run's configuration resolution now has its own provider rate-limit window (PLUMBER_PROVIDER_LIMIT_RESOLVE, default 300 per minute), so it no longer waits behind the nightly snapshot sweep nor competes with the UI.
- A project that keeps pushing verified Plumber results from its default branch is no longer demoted to lost when the sync cannot recognise its self-hosted component include.
- When Plumber refuses to rewrite a protected branch because its rules grant specific users or groups, the fix history now says which branch and setting to adjust in GitLab instead of showing an internal error.
- A fix that fails because your sign-in session expired now says so in plain words in the fix history, instead of an internal message.
- A snapshot refresh that runs out of time now stops calling the provider at once and is retried four times at most, so a slow project no longer blocks its own later refreshes for days.
- When GitLab refuses one part of a project's nightly snapshot (rate limit, server error), that part now keeps its previous value for up to two days, dated, instead of turning the related controls not evaluable overnight.
- A project that stays onboarded because its verified pushes prove the job runs no longer loses its displayed component version and update state overnight.
- When an onboarding or removal fails because your sign-in session expired, its history now says so in plain words and tells you to sign in and start it again.



### New
- Users can create, list and revoke personal access tokens that give an AI agent read-only access through the MCP endpoint.
- A Model Context Protocol endpoint (POST /api/v1/mcp, off by default, PLUMBER_MCP_ENABLED) lets an AI agent such as Claude Code read projects, issues, policies and scores with the same visibility as the user whose token it carries.
- Settings has a new Personal access tokens section where you can create read-only tokens that let your own AI agent (Claude Code, Cursor or any MCP client) read Plumber through the MCP endpoint, and revoke them at any time.
- Keep a per-project Notion database of score push adopters
